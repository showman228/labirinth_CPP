# 🌀 Labyrinth — консольная игра-лабиринт

Простая консольная игра на C++, в которой нужно собрать 5 очков, находя точки (`!`) в лабиринте.

---

## 🎮 Как играть

- Управляй персонажем (`@`) с помощью клавиш `W A S D`
- Найди все **5 точек** (`!`) — после каждой находки новая точка появляется в случайном месте
- Чтобы выйти из игры — нажми `e`

### Управление
| Клавиша | Действие |
|---------|----------|
| `W`     | Вверх    |
| `S`     | Вниз     |
| `A`     | Влево    |
| `D`     | Вправо   |
| `E`     | Выход    |

> ⚠️ После каждой клавиши нужно нажимать **Enter**

---

## 🛠️ Сборка и запуск

### Требования

- Компилятор с поддержкой **C++20**: `clang++` или `g++`
- *(опционально)* CMake 3.10+

---

### Вариант 1: clang++ (рекомендуется)

```bash
clang++ -std=c++20 main.cpp -o labyrinth
./labyrinth
```

### Вариант 2: g++

```bash
g++ -std=c++20 main.cpp -o labyrinth
./labyrinth
```

### Вариант 3: через CMake

```bash
mkdir build && cd build
cmake ..
cmake --build .
./labyrinth
```
